# 🎮 Dota Coach

Легальный оверлей-помощник для Dota 2 на базе **официального GSI** (Game State Integration). Никаких читов и вмешательства в игру — только чтение данных, которые Dota 2 сама отдаёт, и полезные подсказки поверх.

## ✨ Возможности

- ⏱ **Тайминги предметов** — подсказки, когда покупать ключевые предметы (Arcane Boots, Blink, Aghanim's)
- ⚔ **Анализ угроз врага** — что собирает враг и чем это контрить
- 🎁 **Нейтральные предметы** — советы по артефактам и чарам для текущего тира
- 📦 **Лог покупок** — кто что купил, в реальном времени
- 📊 **KDA-таблица** — ценность игроков по формуле `K*1.0 + A*0.6 - D*1.2`
- 🛒 **Стартовый закуп** — рекомендации по роли героя
- 🔊 **TTS-озвучка** — голосовые предупреждения (мало HP, Рошан, тайминг)
- 🤖 **ИИ-анализ матча** — разбор игры от DeepSeek (хоткей F8)
- 🖱 **Единое меню** — управление окнами, хоткеями, размерами и прозрачностью

## 🚀 Установка для новичков (Windows)

### Шаг 0. Установите Python

1. Скачайте Python 3.10+ с официального сайта: <https://www.python.org/downloads/>
2. При установке **обязательно поставьте галочку «Add Python to PATH»** ✅
3. Проверьте: откройте командную строку (Win+R → введите `cmd` → Enter) и наберите:
   ```
   python --version
   ```
   Если видите версию (например `Python 3.12.1`) — всё готово.

### Шаг 1. Скачайте проект

**Способ А — без Git (проще всего):**
1. Нажмите зелёную кнопку **`<> Code`** наверху этой страницы
2. Выберите **Download ZIP**
3. Распакуйте архив в удобную папку, например `C:\dota_coach`

**Способ Б — через Git (если установлен):**
```bash
git clone https://github.com/BitStopSU/dota_coach.git
cd dota_coach
```

### Шаг 2. Откройте папку проекта в командной строке

Откройте `cmd`, затем наберите (подставьте свою папку):
```bash
cd C:\dota_coach
```

### Шаг 3. Установите зависимости

```bash
python -m pip install -r requirements.txt
```
Подождите, пока всё скачается (может занять пару минут).

### Шаг 4. Подключите GSI к Dota 2

1. Из папки проекта скопируйте файл `gamestate_integration_coach.cfg` в папку:
   ```
   Steam\steamapps\common\Dota 2 Beta\game\dota\cfg\gamestate_integration\
   ```
   > Если папки `gamestate_integration` нет — просто создайте её.
2. В Steam: **Библиотека → ПКМ по Dota 2 → Свойства → Параметры запуска** и добавьте:
   ```
   -gamestateintegration
   ```
3. Перезапустите Dota 2, если она была открыта.

### Шаг 5. (Опционально) Настройте ИИ-анализ

ИИ-разбор матча работает через DeepSeek. Ключ можно бесплатно получить на <https://platform.deepseek.com>.

1. Создайте в папке проекта файл `config.json` (или отредактируйте существующий)
2. Вставьте в секцию `"ai"` свой ключ:
   ```json
   "ai": {
       "provider": "deepseek",
       "deepseek_api_key": "sk-ваш-ключ",
       "language": "ru"
   }
   ```
> ⚠️ Никогда не публикуйте свой ключ в интернете и не выкладывайте `config.json` с ним в открытый репозиторий!

### Шаг 6. Запустите!

```bash
python main.py
```
Запустите матч в Dota 2 — оверлеи появятся сами.

## ❓ Частые проблемы

**«python не является внутренней или внешней командой»**
→ Python не добавлен в PATH. Переустановите Python с галочкой «Add Python to PATH».

**Оверлеи не появляются в игре**
→ Проверьте: файл `.cfg` лежит в нужной папке, в параметрах запуска есть `-gamestateintegration`, Dota 2 перезапущена.

**`pip install` выдаёт ошибки**
→ Убедитесь, что у вас Python 3.10+ и выполните:
```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

**Окна перекрывают игру / не на месте**
→ В меню (Del) можно настроить позиции, размер и прозрачность каждого окна.
